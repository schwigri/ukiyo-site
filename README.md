# UkiyoSite

> **<span lang="ja">浮世</span> u·ki·yo** /ɯ̟ᵝkʲijo̞/ *noun* a state of mind
> emphasizing living in the moment, detached from the difficulties of life

The source code for my personal blog.

## Description

UkiyoSite is part of the Ukiyo system which maintains and pubslishes my personal
website and Gemini capsule by separating concerns across codebases, allowing for
long-term stability and flexibility.

The goal of this codebase is to create beautiful, accessible website using the
contents provided via separate repository.
